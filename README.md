# Kalkulus

Kalkulus est une application desktop Windows personnelle pour suivre les ressources, les prix et les ventes dans **Dofus** : catalogue d'objets, prix de référence par serveur/personnage avec historique, lots achetés/revendus via l'Hôtel de Vente, ventes individuelles, tableau de bord (profit, graphiques, objectif de kamas), comparaison entre serveurs, et une calculatrice intégrée.
